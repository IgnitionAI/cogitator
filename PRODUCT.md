# Product

## Register

product

## Users

Developers who already run pi locally. They open Cogitator in a browser to orchestrate agents, workspaces, conversations, providers and cron without leaving the pi ecosystem.

## Product Purpose

Cogitator is the web control panel for pi: compose agents (provider + model + thinking + skills + MCP + prompt + subagents), bind them to disk workspaces, stream conversations, schedule cron runs, and edit pi config. Success is a dense, trustworthy tool that disappears into the task.

## Brand Personality

Precise, industrial, quiet. Three words: exact, dense, unobtrusive. Feels like a well-cut IDE panel (Linear, not a marketing dashboard).

## Anti-references

- Generic SaaS card grids with emoji navigation
- Over-decorated AI consoles (glow, glass, gradient type)
- Modal-first CRUD that hides the work
- Bounce, elastic motion, page-load choreography
- Light or cream admin templates

## Design Principles

- The tool disappears into the task: density over decoration.
- One vocabulary everywhere: same buttons, rows, badges, empty states.
- State over spectacle: motion only for feedback, reveal, and spatial continuity.
- Show the work: conversations, files, and cron runs are first-class.
- Native first: keyboard, focus, labels, reduced motion.

## Accessibility & Inclusion

WCAG 2.2 AA. Visible `:focus-visible` rings. Every icon-only control named. Reduced motion keeps opacity, drops movement. French UI. Single dark theme in v1 (local control tool).

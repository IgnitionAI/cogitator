# Plan 0001 — Cogitator MVP

Status: active
Created: 2026-10-06

## Objective

A usable single-user MVP: spawn pi conversations configured by agent presets from a browser, with workspaces and an initial cron implementation.

## Milestones

| Milestone | Contents | Exit criterion |
|---|---|---|
| **M0 — Skeleton** ✅ (2026-10-06) | Repository tooling (strict TS, vite, tests), native HTTP server + health, SQLite (schema migration v1), minimal pi extension (`/cogitator` → detached server), standalone executable | `npx @ignitionai/cogitator` responds on 5320; `pi` loads the extension without errors |
| **M1 — Registry + Agents** ✅ (2026-10-06) | Provider/model/skill read model from pi files; preset CRUD + validation; Apply herdr `noo-*.md`; pi-mcp-adapter detection | Checklist items 5, 6 passing; a complete preset can be created through the API |
| **M2 — Conversations** ✅ (2026-10-06) | PiProcessPool (spawn flags, idle recycling, max 8), REST + SSE messages, stop, model switch, standalone conversations | Checklist items 1, 2, 8, 9 passing; streaming chat in the browser |
| **M3 — Workspaces** ✅ (2026-10-06) | CRUD + server-side file picker + attached conversations + default agent | Checklist item 4 passing |
| **M4 — MCP** ✅ (2026-10-06) | User-level `mcp.json` screen/configuration; `registerMcpServer` per preset | Checklist item 3 passing |
| **M5 — Cron** ✅ (2026-10-06) | CronService (expressions, busy-guard, catchup), manual trigger, run history, SSE notifications | Checklist item 7 passing |
| **M6 — Complete UI + publish** ✅ (2026-10-06) | 6 React screens, polish, README, publication of `@ignitionai/cogitator` v0.1.0 | Entire checklist passing |

## Recommended order

M0 → M1 → M2 → M3 → M4 → M5 → M6. M2 is the core of the product; if a shortcut is tempting, this is where not to take one (the pool and frozen snapshot are the architectural contract).

# Plan 0001 — MVP Cogitator

Statut : actif
Créé : 2026-10-06

## Objectif

Un MVP utilisable solo : spawner des conversations pi configurées par des presets d'agents depuis un navigateur, avec workspaces et un premier cron.

## Jalons

| Jalon | Contenu | Critère de sortie |
|---|---|---|
| **M0 — Squelette** ✅ (2026-10-06) | Repo tooling (TS strict, vite, tests), serveur HTTP natif + health, SQLite (schema migration v1), extension pi minimale (`/cogitator` → serveur détaché), bin standalone | `npx @ignitionai/cogitator` répond sur 5320 ; `pi` charge l'extension sans erreur |
| **M1 — Registry + Agents** | Read model providers/modèles/skills depuis les fichiers pi ; CRUD presets + validation ; Apply herdr `noo-*.md` ; détection pi-mcp-adapter | Checklist items 5, 6 verts ; un preset complet créable depuis l'API |
| **M2 — Conversations** | PiProcessPool (spawn flags, idle-recycle, max 8), REST + SSE messages, stop, switch modèle, conversations libres | Checklist items 1, 2, 8, 9 verts ; chat streaming dans le navigateur |
| **M3 — Workspaces** | CRUD + file-picker serveur + conversations rattachées + agent par défaut | Checklist item 4 vert |
| **M4 — MCP** | Écran/config `mcp.json` user-level ; `registerMcpServer` par preset | Checklist item 3 vert |
| **M5 — Cron** | CronService (expressions, busy-guard, catchup), fire manuel, runs history, notifications SSE | Checklist item 7 vert |
| **M6 — UI complète + publish** | 6 écrans React, polish, README, publication `@ignitionai/cogitator` v0.1.0 | Toute la checklist verte |

## Ordre recommandé

M0 → M1 → M2 → M3 → M4 → M5 → M6. M2 est le cœur du produit ; si un raccourci est tentant, c'est là qu'il ne faut pas en prendre (le pool et le snapshot figé sont le contrat architectural).
